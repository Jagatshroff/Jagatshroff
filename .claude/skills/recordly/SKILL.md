# Recordly

Open-source screen recorder + editor (`webadderallorg/Recordly`). Records and edits screen
captures with motion-driven presentation tools (zooms, cursor polish, backgrounds) in one app.

## Where it lives
Cloned at `~/tools/Recordly`. Project site: https://www.recordly.dev

## How to use
- Desktop app — build/run per the repo README for the target OS. It needs a GUI/display,
  so it runs on the user's own machine, not this headless container.

## When to use
Creating polished demo/walkthrough/product videos from screen recordings. Not runnable here.
