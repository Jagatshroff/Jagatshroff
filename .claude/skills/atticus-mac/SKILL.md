# Atticus (Mac)

Free open-source macOS assistant (`SaarthurR/atticus-mac`). Hold ⌃⌥Space, say what you need;
it arranges windows, finds files, reads the screen, and answers about anything you circle.
No API key; learns as you use it.

## Where it lives
Cloned at `~/tools/atticus-mac`.

## How to use
- Native macOS app — build/install per the repo README on the user's own Mac. It controls
  the desktop and reads the screen, so it cannot run in this Linux container.

## When to use
Installing or learning about Atticus. Not runnable here — it's a macOS desktop assistant.
