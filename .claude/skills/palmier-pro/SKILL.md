# Palmier Pro

"The video editor built for AI" (`palmier-io/palmier-pro`). macOS 26 (Tahoe) on Apple Silicon.

## Where it lives
Cloned at `~/tools/palmier-pro`.

## Notes
- Releases through v0.7.6 and the `last-gpl-source` branch are GPLv3; later binary releases
  are proprietary (source not published). This repo hosts historical source + current binaries.
- It is a native macOS desktop app — installing/running it requires the user's own Mac
  (this Linux container can't run it). Point the user to the repo's Releases for the binary.

## When to use
Installing or reading about Palmier Pro, or retrieving its GPL-era source. Not runnable here.
