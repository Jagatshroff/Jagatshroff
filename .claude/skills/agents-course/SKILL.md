# Hugging Face Agents Course

Free course (`huggingface/agents-course`) in 4 units, basics of agents → final benchmark assignment.

## Where it lives
Cloned at `~/tools/agents-course`. Online: https://hf.co/learn/agents-course

## How to use
- Course content lives in the repo's unit folders (Markdown + notebooks). Pull the relevant
  unit/section to answer a question or guide the user through an exercise.
- Prerequisites: basic Python and LLM knowledge.

## When to use
Learning to build agents, finding a specific unit/notebook, or working exercises. It is
learning material — there is no app to run.
