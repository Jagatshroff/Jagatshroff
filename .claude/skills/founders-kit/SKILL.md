# Founders Kit

Curated reference collection (`avinash201199/founders-kit`) of tools and resources for
founders, organized by startup stage and function.

## Where it lives
Cloned at `~/tools/founders-kit`. It is a content/resource repo (Markdown + links),
not an executable app — there is nothing to run.

## How to use
- Read the repo's README and category files to surface tools for a given need
  (product development, marketing, fundraising, team management, analytics, etc.).
- When the user asks "what should I use for X as a founder," pull the relevant
  entries from the kit and summarize, with the links.

## When to use
Tool/resource recommendations for a startup task or stage. Not for writing a business
plan or financial model — use the founder-skill / seed-skill packs for that.
